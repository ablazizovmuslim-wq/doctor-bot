# Шифокор ёрдамчи боти

## Бот нима қилади
1. /start босилганда тил танланади: ўзбекча ёки русча.
2. Бот 3 та савол беради:
   - Охирги ҳайз қачон бошланган? (сана, масалан 05.11)
   - Цикл одатда неча кун? (21–35 тугмалар ёки рақам)
   - Ҳайз доим бир хил келадими?
3. Агар доим бир хил келса, бот санада ёзиб беради:
   - овуляция куни (кейинги ҳайз санасидан 14 кун айирилади),
   - ҳомиладор бўлиш эҳтимоли энг юқори кунлар,
   - кейинги ҳайз санаси.
   Агар ўзгариб турса, шифокорга бориш ва УЗИ қилдиришни маслаҳат беради. Ҳайз кечикаётган бўлса, огоҳлантиради.
4. «❓ Бошқа савол» тугмаси орқали мижоз хоҳлаган саволини ёзади ва Claude жавоб беради.

Ҳисоблаш қисми бепул ишлайди, Claude'га пул фақат «Бошқа савол»да кетади.

## Файллар
- `bot.py` — ботнинг асосий коди
- `texts.py` — ботдаги барча матнлар (ўзбекча ва русча). Матнни ўзгартириш учун шу файлни таҳрирланг.
- `prompt.py` — Claude учун йўриқнома: нимага жавоб бериши ва нимага бермаслиги
- `.env.example` — созламалар намунаси

## Railway'га қўйиш
1. Кодни GitHub'га юкланг ва Railway'да **New Service → GitHub repo** ни танланг.
2. **Variables** бўлимига қўшинг:
   - `BOT_TOKEN` — @BotFather берган токен
   - `ANTHROPIC_API_KEY` — platform.claude.com даги калит
   - `ADMIN_ID` — акангизнинг Telegram ID рақами (@userinfobot орқали билиш мумкин)
   - `CLAUDE_MODEL` — `claude-sonnet-5-5` (арзонроғи: `claude-haiku-5-5`)
   - `DB_PATH` — `/data/bot.db`
   - ихтиёрий: `DOCTOR_NAME`, `DOCTOR_CONTACT`, `DOCTOR_INFO`, `DAILY_LIMIT` (одатда 15)
3. **Volume** қўшинг ва уни `/data` га уланг. Шунда статистика ва тиллар ўчиб кетмайди.
4. Deploy қилинг. Логда «Bot ishga tushdi» чиқса, бот ишлаяпти.

## Акангиз учун
- `/stats` — фойдаланувчилар сони, бугунги ва ойлик саволлар, Claude'га кетган тахминий пул.
- Claude балансидаги пул тугаса, бот акангизга Telegram'да хабар юборади.
- Claude кабинетида (platform.claude.com) ойлик сарф лимитини қўйиш ва auto-reload'ни ўчириб қўйиш тавсия этилади.
